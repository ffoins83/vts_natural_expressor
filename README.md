# VTS Natural Expressor

表情差分をパラメータに対するルールベースで自動適用するVTubeStudioのプラグイン（Win）です。わざとらしく表情差分を自分で適用するのをやめよう！

## インストール・起動

1. このフォルダを落としてきます。
2. `build_windows.bat` をダブルクリックします。
3. 初回はビルド用のPythonとパッケージをこのフォルダ内にダウンロードします。インターネット接続が必要です。
4. ビルドが完了すると、同じフォルダに `VTS Natural Expressor.exe` が作成されます。

PythonをWindowsへインストールする必要はありません。ビルド環境は `.build_tools` に保存され、次回から再利用されます。

EXEファイルを起動して利用します。起動中のみ反応します。

## 設定

`profiles.json` にプロファイルとルールを保存します。アプリと同じフォルダに置いてください（基本的に自分で弄る必要はありません）。

VTube Studioの設定（歯車アイコン）から「VTubeStudio Plugin」の「APIの起動（プラグインを許可）」を有効にし、EXEアプリからURLを合わせて「接続」してください。初回起動時はVTubeStudio側でアクセスの許可が必要となるので、許可してください。
